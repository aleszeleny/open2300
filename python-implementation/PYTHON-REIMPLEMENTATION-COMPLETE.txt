PROJECT STRUCTURE
-----------------

New Python Package: pyopen2300/
  ├── Core modules (4 files):
  │   ├── __init__.py          - Package initialization
  │   ├── constants.py         - Protocol constants
  │   ├── config.py            - Configuration management
  │   ├── serial_comm.py       - Serial communication
  │   └── weatherstation.py    - WS2300 protocol
  │
  └── CLI tools (16 commands):
      ├── open2300             - Low-level operations
      ├── dump2300             - Memory dump
      ├── bin2300              - Binary dump
      ├── dumpconfig2300       - Show config
      ├── fetch2300            - Fetch data
      ├── log2300              - Log to file
      ├── xml2300              - XML export
      ├── wu2300               - Weather Underground
      ├── pgsql2300            - PostgreSQL logging
      ├── sqlitelog2300        - SQLite logging
      ├── light2300            - LCD control
      ├── interval2300         - History interval
      ├── minmax2300           - Reset min/max
      ├── history2300          - Read history
      └── histlog2300          - Log history

Supporting Files:

INSTALLATION
------------

Quick start:

  cd /home/zelenya/src/open2300
  pip install -r requirements.txt
  pip install -e .
  cp open2300-dist.conf open2300.conf
  # Edit open2300.conf to set your serial device
  dumpconfig2300

USAGE EXAMPLES
--------------

# Check configuration
dumpconfig2300

# Read raw memory
open2300 346 r 2

# Fetch all weather data
fetch2300

# Log to file
log2300 /var/log/weather.log

# Upload to Weather Underground
wu2300

# Log to database
sqlitelog2300 weather.db

# Control backlight
light2300 on
