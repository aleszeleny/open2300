KEY DIFFERENCES: REQUIREMENTS FILES
------------------------------------

requirements.txt (x86/x64):
  - pyserial>=3.5
  - psycopg2-binary>=2.9.0 (pre-built wheels)
  - Fast installation

requirements-rpi.txt (Raspberry Pi):
  - pyserial>=3.4 (better compatibility)
  - psycopg2>=2.8.0 (commented, build from source)
  - Slower installation but works on ARM

WHY SEPARATE FILES?
-------------------

1. Architecture Differences
   x86/x64: Uses pre-compiled binary wheels
   ARM:     May need to build from source

2. Package Availability
   psycopg2-binary: Has x86/x64 wheels, limited ARM support
   psycopg2:        Builds from source, works on all platforms

3. Version Compatibility
   Older RPi models may have older Python/pip versions
   Using >=3.4 ensures broader compatibility

4. Optional Dependencies
   PostgreSQL is more optional on RPi due to resource constraints
   SQLite recommended for RPi2

INSTALLATION COMPARISON
-----------------------

x86/x64 System:
  $ pip install -r requirements.txt
  $ pip install -e .
  Time: ~30 seconds

Raspberry Pi 2:
  $ pip3 install -r requirements-rpi.txt
  $ pip3 install -e .
  Time: ~3-5 minutes (builds from source)

Raspberry Pi 4:
  $ pip3 install -r requirements-rpi.txt
  $ pip3 install -e .
  Time: ~1-2 minutes

RECOMMENDATIONS BY PLATFORM
----------------------------

Raspberry Pi 2:
  - Use requirements-rpi.txt
  - Use SQLite (not PostgreSQL server)
  - Log every 5+ minutes
  - Serial: /dev/ttyAMA0

Raspberry Pi 3/4:
  - Use requirements-rpi.txt
  - Can use PostgreSQL or SQLite
  - Can log more frequently
  - Serial: /dev/ttyAMA0

x86/x64 Desktop/Server:
  - Use requirements.txt
  - PostgreSQL recommended
  - Can log very frequently
  - Serial: /dev/ttyS0 or /dev/ttyUSB0

COMMON ISSUES ADDRESSED
-----------------------

Issue: "Cannot install psycopg2-binary on ARM"
Solution: Use requirements-rpi.txt which uses psycopg2 instead

Issue: "Installation takes forever"
Solution: Normal on RPi2 - packages build from source (3-5 min)

Issue: "Cannot open serial device"
Solution: Add user to dialout group, enable serial in raspi-config

Issue: "Out of memory during install"
Solution: Temporarily increase swap space (see guide)

EXAMPLE USAGE
-------------

On Raspberry Pi 2:

  # Install
  cd /home/zelenya/src/open2300
  pip3 install -r requirements-rpi.txt
  pip3 install -e .

  # Configure
  cp open2300-dist.conf open2300.conf
  nano open2300.conf  # Set SERIAL_DEVICE /dev/ttyAMA0

  # Setup
  sudo raspi-config   # Enable serial
  sudo usermod -a -G dialout $USER
  logout && login

  # Test
  fetch2300

  # Automate
  crontab -e
  # Add: */5 * * * * /usr/local/bin/sqlitelog2300 /home/pi/weather.db
