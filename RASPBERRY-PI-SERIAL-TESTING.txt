STEP 1: ENABLE SERIAL PORT
---------------------------
Before using the test script, enable the GPIO serial port:

    sudo raspi-config

Navigate to:
    Interfacing Options → Serial Port

Answer the questions:
    - Login shell over serial? → NO
    - Serial hardware enabled?  → YES

Reboot:
    sudo reboot


STEP 2: INSTALL REQUIREMENTS
-----------------------------
The test script needs pyserial:

    pip3 install pyserial

Or install all requirements for the project:

    cd /home/zelenya/src/open2300
    pip3 install -r python-implementation/requirements-rpi.txt


STEP 3: RUN THE TEST SCRIPT
----------------------------

For GPIO serial port (ttyAMA0):

    python3 python-implementation/test_serial_port.py -d /dev/ttyAMA0

For USB-to-serial adapter:

    python3 python-implementation/test_serial_port.py -d /dev/ttyUSB0

The script will automatically detect Raspberry Pi GPIO ports!


RASPBERRY PI SERIAL DEVICES
----------------------------

Device           Description                    Recommended
------           -----------                    -----------
/dev/ttyAMA0     Primary GPIO UART              ✓ Best choice
/dev/serial0     Symlink to primary UART        ✓ Also good
/dev/ttyS0       Mini UART (some models)          Less reliable
/dev/ttyUSB0     USB-to-serial adapter          ✓ Works great


QUICK TROUBLESHOOTING
---------------------

Problem: "Device does not exist"
Solution: 
    1. Enable serial in raspi-config (see Step 1)
    2. Check: ls -l /dev/ttyAMA0 /dev/serial0
    3. Reboot if needed

Problem: "Permission denied"
Solution:
    sudo usermod -a -G dialout $USER
    # Log out and log back in

Problem: "Device is busy"
Solution:
    # Disable serial console
    sudo systemctl stop serial-getty@ttyAMA0.service
    sudo systemctl disable serial-getty@ttyAMA0.service

Problem: pyserial not installed
Solution:
    pip3 install pyserial

CONFIGURING FOR WS2300
-----------------------

After testing, update your configuration:

    cd /home/zelenya/src/open2300
    nano open2300.conf

Set the serial device:

    SERIAL_DEVICE /dev/ttyAMA0

Save and test:

    fetch2300


USING USB-TO-SERIAL ADAPTER
----------------------------

If you prefer a USB adapter instead of GPIO:

1. Plug in USB-to-serial adapter
2. Find the device:
       ls -l /dev/ttyUSB*
3. Test it:
       python3 python-implementation/test_serial_port.py -d /dev/ttyUSB0
4. Update config:
       SERIAL_DEVICE /dev/ttyUSB0

HARDWARE SETUP OPTIONS
-----------------------

Option 1: Direct GPIO Connection
    WS2300 Serial → Level Shifter → GPIO pins (TXD0/RXD0)
    Device: /dev/ttyAMA0

Option 2: USB-to-Serial Adapter (Recommended)
    WS2300 Serial → USB Adapter → Raspberry Pi USB port
    Device: /dev/ttyUSB0
    
    Benefits:
    - No level shifter needed
    - Easier to connect/disconnect
    - Works immediately without raspi-config
    - Can move between Raspberry Pi units easily

AUTOMATED WEATHER LOGGING ON RASPBERRY PI
------------------------------------------

Once serial port is working, set up automated logging:

    # Edit crontab
    crontab -e

    # Log to SQLite every 5 minutes
    */5 * * * * /usr/local/bin/sqlitelog2300 /home/pi/weather.db

    # Upload to Weather Underground every 15 minutes
    */15 * * * * /usr/local/bin/wu2300

Perfect for long-term unattended weather monitoring!
